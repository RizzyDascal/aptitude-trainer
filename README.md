# Aptitude Trainer

Installable aptitude-test practice app (number sequences, odd one out, verbal, logic, abstract, spatial, picture comparison, maths, coding). 15,000+ machine-validated questions with adaptive difficulty.

**Install on a phone:** open the site link, then iPhone Safari → Share → *Add to Home Screen*, or Android Chrome → ⋮ → *Install app*. Works offline after the first load. Progress is stored on the device (Settings → Export backup to save a copy).
